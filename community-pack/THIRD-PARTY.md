# Third-party components

| Component | Used for | Licence | Shipped? |
|---|---|---|---|
| [Settlers-DNG-Patches](https://github.com/S2-modders/Settlers-DNG-Patches) (zocker_160, S2-modders) | base of the patch DLL (widescreen, zoom, lobby, Vulkan) | GPL-3.0 | yes – as part of `d3d9.dll`, source in this repository |
| [CppUtility](https://github.com/zocker-160/CppUtility) (zocker_160) | helper library of the patch | MIT | yes – inside `d3d9.dll` |
| [SimpleIni](https://github.com/brofield/simpleini) (Brodie Thiesfield) | ini parsing (via CppUtility) | MIT | yes – inside `d3d9.dll` |
| [S2-10th-Anniversary-decrypter](https://github.com/S2-modders/S2-10th-Anniversary-decrypter) (S2-modders) | installer: decrypts your own game files | MIT | yes – `tools\decryptor_s2.exe` (unchanged build), licence in `tools\decryptor_s2.LICENSE.txt` |
| [Settlers-II-remakes-4k-textures-dds](https://github.com/S2-modders/Settlers-II-remakes-4k-textures-dds) (S2-modders) | optional HD textures; LOD values of `LODFix` | no licence stated | **no** – downloaded by the installer from the original repository at your request |
| [Real-ESRGAN ncnn-vulkan](https://github.com/xinntao/Real-ESRGAN) (Xintao Wang et al.) | optional 2× interface upscaling | BSD-3-Clause | **no** – downloaded from the official release at your request |
| [DirectXTex texconv](https://github.com/microsoft/DirectXTex) (Microsoft) | optional DDS conversion | MIT | **no** – downloaded from the official release at your request |
| DXVK (`d3d9vk.dll`) | Vulkan renderer | zlib | no – part of the Community Patch 2.3 |

Game content (*The Settlers II – 10th Anniversary*, © Ubisoft Entertainment / Blue Byte / Funatics) is **not** included.
All modified shaders, settings and interface textures are generated by `install.ps1` from the user's own installation.
